# 🛍️ Mankelvo Market

**Mankelvo Market** is a modern React e-commerce web application built to provide a clean and responsive online shopping experience.

The project currently allows users to browse products, search and filter items, view product details, add products to a persistent shopping cart, and complete a demonstration checkout process.

This application is also being used as the foundation for my **Microsoft Azure Cloud Computing project**, where I will deploy and integrate the application with multiple Azure services.

## ✨ Features

### 🏠 Homepage

The homepage provides an introduction to Mankelvo Market and includes featured products, product categories, and navigation to the main shopping experience.

### 🛒 Product Catalog

Users can browse products from multiple categories including:

- Electronics
- Men's Clothing
- Women's Clothing
- Jewelry

Product information is dynamically retrieved from the Fake Store API.

### 🔎 Search and Filtering

Users can:

- Search products by name
- Filter products by category
- Sort products by price

### 📦 Product Details

Each product has an individual details page containing:

- Product image
- Product title
- Description
- Category
- Price
- Rating
- Add to Cart functionality

### 🛍️ Shopping Cart

The cart allows users to:

- Add products
- Increase quantity
- Decrease quantity
- Remove products
- Clear the cart
- View subtotal and estimated order total

Cart information is stored using browser Local Storage so the cart remains available after refreshing the page.

### 💳 Demo Checkout

Mankelvo includes a demonstration checkout flow where users can enter basic customer and shipping information.

> **Note:** This is a demonstration application. No real payment is processed.

### 🔐 Authentication

A sign-in interface is currently included in the frontend.

Microsoft Entra authentication is planned as part of the Azure cloud implementation.

## ☁️ Microsoft Azure Cloud Project

Mankelvo Market will also be used as a hands-on Microsoft Azure cloud computing project.

The goal is to demonstrate how multiple cloud services can work together to host, secure, monitor, and support a modern web application.

### Planned Azure Architecture

The project is expected to include services such as:

- Azure Virtual Machines
- Azure Virtual Network
- Azure Load Balancer
- Azure Blob Storage
- Azure Table Storage
- Microsoft Entra ID / External ID
- Azure Bastion
- Azure Monitor
- Azure Cost Management and Budget Alerts
- Azure Backup

These services will be implemented incrementally as the cloud portion of the project develops.
